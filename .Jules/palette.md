## 2024-05-24 - Semantic ARIA attributes for visual states
**Learning:** It is crucial to pair visual state changes (e.g., active navigation links, open menus) with corresponding semantic ARIA attributes (`aria-current`, `aria-expanded`) for screen reader accessibility to ensure all users can perceive state changes.
**Action:** Always add semantic ARIA attributes that correspond to visual indicators of active states, open/closed states, or disabled states for custom components.
