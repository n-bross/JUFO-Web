## 2026-10-29 - aria-pressed on toggle buttons\n**Learning:** When using custom filter buttons in React that visually indicate a selected state, it's essential to add `aria-pressed` so screen readers can also perceive which filter is currently active.\n**Action:** Ensure that any element acting as a toggle or filter button, and uses a visual class like `bg-black text-white` for its active state, also includes an `aria-pressed={isActive}` attribute to mirror this state semantically.
