## 2025-01-20 - Navigation State ARIA Alignment\n**Learning:** In React components like `Navbar`, visual cues indicating active states (like underlines or bold text) or menu states (open/closed) were not consistently paired with their respective ARIA semantic states. This created a discrepancy between visual navigation and screen reader navigation.\n**Action:** Always verify that components altering their UI based on route paths (`location.pathname`) also implement `aria-current="page"` on active links. Additionally, state-toggled UI elements (e.g., mobile hamburger menus) must have `aria-expanded` and dynamically updating `aria-label` attributes corresponding to their `open` state.
